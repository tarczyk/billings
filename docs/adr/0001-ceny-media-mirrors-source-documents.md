# `Ceny media` mirrors source documents; tenant-facing items are derived

`Ceny media` holds rates exactly as named and priced in source documents (cooperative monthly statements, Tauron invoices) — one row per source line, no sums, no VAT, no margin. Tenant-facing items (e.g. "Ciepła woda", "Fundusz remontowy", parking with VAT) are computed by formula in a separate `Stawki najemcy` block, which `Szablon` reads. We chose this over tenant names with hand-computed sums because every hand-computed aggregate we found was either wrong or untraceable: `Ciepła woda 59,72` summed three cooperative rates and double-counted cold water, and `Fundusz remontowy 1,80` (= 1,77 + 0,03) was "corrected" to 1,77 because its components were invisible. The cost is maintaining a small mapping layer between two lists.
